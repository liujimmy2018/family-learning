## 本阶段边界

单机试用使用服务端私有文件目录，API 鉴权读取，图片默认 30 天过期清理；云部署的私有对象存储适配尚未实现。云端语音为默认来源，设备离线语音为用户明确选择的备选，需要预先安装对应语音包。

MySQL 5.1 的三字节 utf8 不支持普通文字字段中的表情及扩展汉字；JSON 文本通过转义保留字符，JSON 合法性由 Java 处理。时间精度为秒。二进制日志开启时必须为 ROW，启动检查会拒绝其他日志格式，不自动更改全局设置。Spring Boot 2.7、MySQL 5.1 及配套旧版迁移工具属于历史版本，本次交付用于兼容本地试用，长期生产维护需要另行规划支持与升级。

档案停用会取消相关任务，但不执行物理级联删除；App 未提供误称为“删除”的操作。完整数据删除、语文、数学、判题、错题分析及出题检测属于后续阶段。当前 APK 使用调试签名，尚未完成正式签名发布或应用市场上架。

## 真机试用验收顺序

1. 按 README 启动 MySQL、API 和 Worker，设置邀请码与 AI 密钥。
2. 安装 APK 并设置可访问的服务地址；注册家长账号，创建与切换孩子档案。
3. 导入真实词表照片，检查旋转裁剪、候选词识别、人工纠正和保存。
4. 查询一个单词并播放读音，分别以英文和中文模式执行听写。
5. 检查重复次数、书写间隔、暂停重播、后台返回、断网补传及重开任务恢复。
6. 使用第二个账号确认资源隔离；退出后确认无法继续访问原账号学习资源。
