# Excel 词库、听写计时与家长批改（0.4.1）

## 0.4.1 单元范围与单词卡片

新建听写的标题会保存单元信息，例如“课本词表 · 3年级上册 · Unit 1”；整册范围显示“整册”。听写页、批改页及听写记录使用同一标题。词库名称过长时缩短名称，保留所选单元。旧听写保持原始标题，新建听写即可看到此变化。

听写页提供“单词卡片”，默认隐藏英文答案。点击“暂停并查看”会暂停，显示英文、中文和导入的音标；点击“重播”可对照卡片听读，继续听写或切换词条/轮次时收起。没有音标的记录显示“未提供”，不自动编造音标。旧听写未保存音标时可在批改页查看原答案来源信息；新建词库听写会把音标一同保存在答案快照中。

使用卡片需同时更新0.4.1 App与Java服务；Android versionCode=6，支持覆盖安装。数据库沿用V3，不需要执行SQL或重新导入已有词库。仅标题显示的服务端改进也兼容0.4.0 App。

## 0.4.0 页面与操作

底部为 **英语、语文、数学、我的**。语文和数学仅保留“后续补充”页面。当前学习孩子在英语首页显示，在“我的”选择切换或编辑。

英语首页提供 **开始听写、听写记录、错词本** 三个入口。拍照、手动词表、查词和草稿移到 **我的 → 词表工具**，Web词库维护方式不变。

听写流程：英语 → 开始听写 → 选择词库 → 选择年级与上下册 → 按单元选择某个单元，或选择整册 → 读中文/读英文 → 选择1—10秒等待时间 → 开始听写 → 完成后家长批改 → 保存分数与错词 → 返回听写记录。

等待时间从当前词全部播报完成后开始。默认按词库顺序逐词听写，随机抽取、重复次数、轮次和倒计时放在“更多设置”。词库单次支持最多500词、多轮批改最多1500题；手动词表仍保留单次100词限制。旧听写记录保留创建时的设置，不会因为新界面的1—10秒范围被改写。

“听写记录”可按全部、进行中、待批改、已批改筛选，查看日期、用时、完成状态和成绩，并支持加载更多。未批改的成绩显示为空，实际0分成绩会正常显示。成绩仍由家长逐题标记后自动计算，提交后固定保存。

0.4.0需要同时升级服务端和安卓端：新增历史查询接口，并允许1、2秒等待时间。沿用V3数据库结构，没有新增迁移脚本；若已运行0.3.0，不需要重新建表或重新导入词库。

## 本地升级

本次需要同时升级安卓 App 和 Java 服务。继续兼容 JDK 1.8、MySQL 5.1.42，全部业务主键均为 UUID，无自增列。数据库沿用你当前已能启动的库（例如现有 `family_learning`），不要重新建库或重复执行旧 V1/V2 SQL。

1. 先备份当前数据库，停止 Eclipse 中原有的 Java 服务。
2. 刷新 `family-learning-server` 工程，在 Eclipse 执行 **Maven → Update Project** 下载新增的 Apache POI 5.5.1 依赖，然后 **Project → Clean** 重新构建。服务端仍选 JDK 1.8；原有账号、数据库连接和邀请码配置继续保留。
3. 按原来的 `FamilyLearningLocal.launch` 启动。已使用0.3.0的数据库保持V3，无需执行SQL；从更早版本首次升级时，Flyway在V2基础上自动执行 `V3__catalog_and_dictation_review.sql`，新增词库、词条、批改和错词四张表，总计16张业务表，加迁移历史表共17张。**不要在自动迁移后再次手动执行 V3。**
4. 电脑浏览器打开 `http://localhost:8080/web/`。同一局域网其他设备可将 `localhost` 改为电脑 IP。网页使用与 App 相同的家长账号登录，词库按家长账号隔离。
5. 手机覆盖安装 `artifacts/family-learning-0.4.1-debug.apk`，无需先卸载。服务器地址仍在“我的 → 服务器管理”或登录页“选择 / 管理服务器”中维护。

V3 SQL：[迁移脚本](../server/src/main/resources/db/mysql51-uuid/V3__catalog_and_dictation_review.sql)。脚本已经在独立 MySQL 5.1.42 测试库上验证；本次开发没有对你3306端口的实际数据库执行升级。

也可使用新的 JAR 启动，放在 `server` 目录作为工作目录，并通过环境变量设置 `DB_URL`、`DB_USER`、`DB_PASSWORD`。便携包的默认库名为 `family_learning_uuid`，若使用现有 `family_learning`，必须在 `DB_URL` 中明确指定。Web词库、家长批改、设备语音不依赖云端 AI 和 Worker；原有云端功能继续按原配置使用。

便携打包资源位于 `server/packaging/portable/application.yml`，仅供 Maven 的 `portable` profile 使用，不放在 Spring Boot 会自动扫描的 `server/config/*/` 下。若日志出现 `Access denied for user 'family' ... (using password: NO)`，但源码明明配置了其他账号，应先检查是否加载了额外配置。本工程已移除旧 `config/portable/application.yml`，刷新工程并重新启动即可；不要为解决配置覆盖问题去创建或授权 `family` 用户。

## Excel 约定

在网页“词表管理”点击“下载 Excel 模板”。模板带3行示例，整理自己的词表时请替换示例。

第一个工作表首行固定为以下六列，不需要增加标题行或合并单元格：

| 年级 | 上下册 | 所属单元 | 中文 | 英文 | 音标 |
| --- | --- | --- | --- | --- | --- |
| 3 | 上册 | Unit 1 | 苹果 | apple | /ˈæpəl/ |
| 3 | 上册 | Unit 1 | 香蕉 | banana | /bəˈnɑːnə/ |
| 3 | 上册 | Unit 2 | 书 | book | /bʊk/ |

- 仅支持 `.xlsx`，每文件最多8MB、5000个数据行；年级为1—6，册别仅为“上册”或“下册”。
- 单元名称自定义，建议统一为 `Unit 1`、`Unit 2` 等。一个词表可包含多个年级、册别和单元；不同教材版本建议导入为独立词表，并在词表名称中说明版本。
- 中文、英文、单元必填；音标可空。长度限制：单元40、中文300、英文100、音标200字符。MySQL 5.1 三字节 utf8 不支持表情及扩展汉字。
- 同一个词表内，“年级 + 上下册 + 单元 + 规范化英文”不得重复。英文去除首尾空格、合并连续空白并忽略大小写判重。跨单元同词允许。
- 不支持公式、错误单元格、加密工作簿或宏；请粘贴为纯文本。上传会先校验并展示错误行，全部修正后再确认导入。预览仅展示前100条有效数据，确认导入保存全部有效行，不会静默跳过错误。
- 重新导入创建一份独立词表；维护已有词表请在网页编辑、新增或删除单词。并发编辑使用版本号，提示冲突时请刷新后重试。

## App 听写

1. 在 App **我的**选择孩子，然后 **英语 → 开始听写**，需要时点击刷新。
2. 选择词库、年级和上下册。
3. 选择“按单元”或“整册”。在更多设置中可选择随机抽取；每次最多500词，抽取数量不能超过所选范围的词数。抽样由服务端完成，创建成功后词序和答案固定保留，重试不会重新抽样。
4. 选择“读中文”或“读英文”，两种模式均在纸上写英文；设置每词等待1—10秒。“更多设置”可调整播报次数、轮次和倒计时。
5. 开始听写。词库听写默认使用**设备离线语音**，需要手机安装相应的中文、英语语音包。此路径没有云端调用费，音标用于展示，发音由设备语音引擎提供。

有效练习用时从开始倒计时起统计，包含播报和书写间隔，暂停、切后台和准备音频不计时；暂停恢复会重播当前词。用时在本机保存并在进度同步时上传，旧版未记录用时的听写显示00:00。网络中断时进度和时间留在本机，恢复网络后同步；建立听写任务、读取新词库、提交批改仍需连接家庭服务。

## 家长批改、评分和错词

完成听写后点击 **家长批改与评分**，或在 **英语 → 听写记录** 中选择 **去批改 / 查看批改详情**。此功能按用户确认的免费家长校对方案实现，不自动识别纸面答案。

- 对照纸面答案的轮次、题号，查看标准英文、中文及音标，逐题标记“正确”或“错误”。错误题可选填孩子实际写的内容。
- 必须标记所有轮次的全部题目才能提交，未批改不当作错误。提前结束或尚未同步完成的听写不能提交整份成绩。
- 分数 = 正确题数 ÷ 总题数 × 100，四舍五入保留一位小数。例如3词2轮共6题，正确4题得66.7分。
- 提交后成绩与批改固定保存；同一内容重复提交返回原结果，不重复累计错词，改变已提交内容会提示冲突。请在确认提交前核对。
- 每个孩子的错词按规范化英文合并，累计每次错误：同一词在两轮都写错，累计2次；以后再错继续累加。
- App **英语 → 错词本** 与 Web **孩子的错词本** 可查看英文、中文、音标、课程范围和错误次数，标记“已掌握”或恢复“待复习”。再次写错会自动恢复待复习，保留累计次数。
- 听写创建时保存答案及来源快照；之后修改、删除词表不会改变已经建立的听写及成绩。网页删除词表是从可选库中移除，不删除历史听写、成绩和错词。
